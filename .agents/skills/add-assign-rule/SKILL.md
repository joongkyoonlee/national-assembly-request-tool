# 소관 과 배분 규칙 보강

## 1. 언제 쓰는지
- `data/배분기준표_소관키워드_304건.csv` 기반 분류 엔진의 1순위 오답을 줄일 때 사용한다.
- 조직도, 시험 40건, 접수대장 520건과 현재 엔진이 입력으로 주어진다.

## 2. 순서
1. 원본 규칙으로 시험 40건과 접수대장 520건의 1순위 결과를 저장하고 오답을 원인별로 묶는다.
2. 원인마다 제외어 추가, 키워드 추가 또는 우선순위 변경 중 한 가지 수정안을 제안하고 사용자 선택을 기다린다.
3. 원본 규칙을 `data/rules_보강.csv`로 복사한 뒤 사용자가 선택한 규칙만 반영한다. 모든 과가 조직도 26개 과 안에 있는지 확인한다.
4. 변경 전·후의 시험 40건과 접수대장 520건 1순위 정확도를 비교하고, 변경 전 정답이 변경 후 오답이 된 새 오답 수를 계산한다.
5. 시험 1순위가 30/40 이상이고 새 오답이 0건일 때만 변경 규칙과 결과를 `PROGRESS.md`에 기록하고 보강 사본을 최종 결과로 남긴다.

## 3. 끝나는 조건
- `data/rules_보강.csv`가 존재하고 원본 규칙 파일은 변경되지 않아야 한다.
- 시험 1순위가 30/40 이상이고 새로 틀린 문항이 0건이어야 한다.
- 시험 40건과 접수대장 520건의 변경 전·후 1순위 정확도가 표로 보고되고 `PROGRESS.md`에 기록되어야 한다.

## 4. 하지 말 것
- 원본 `data/배분기준표_소관키워드_304건.csv`를 수정하지 않는다.
- 사용자가 고르지 않은 수정안을 반영하거나 규칙을 코드에 하드코딩하지 않는다.
- 조직도 26개 과 밖의 과를 추가하지 않는다.
- 정확도가 올라도 새 오답이 생기면 완료로 처리하거나 스킬을 공용 폴더에 설치하지 않는다.
