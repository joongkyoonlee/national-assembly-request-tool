# 절차

`지침재료/`의 01~04 네 원문을 바탕으로 정리했다. 원문은 교육용 가상 자료이며, 줄 번호는 빈 줄을 포함한다. 2025년 대응계획은 2025년 9~10월 국감 집중 기간의 계획이고, 2025년 12월 30일 메일은 새 지침의 시행일을 2026년 9월 1일로 지정한 작성 지시다. 이 정리 자체가 지침의 승인·시행을 입증하지는 않는다. [근거: 01_전임자_인수인계서_국회업무_2025.md 4줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L4), [02_2025국감_대응계획_메모.txt 2~4줄](../지침재료/02_2025국감_대응계획_메모.txt#L2-L4), [03_업무메일_모음_2025국감.txt 61~68줄](../지침재료/03_업무메일_모음_2025국감.txt#L61-L68)

## 1. 담당과 기준 자료 준비

- 총괄은 기획재정담당관이고 각 과 국회 담당자를 1명씩 지정한다. 각 과는 소관 답변과 근거 자료에 책임을 진다. [근거: 02_2025국감_대응계획_메모.txt 5줄](../지침재료/02_2025국감_대응계획_메모.txt#L5), [01_전임자_인수인계서_국회업무_2025.md 8줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L8)
- 조직도·배분기준표는 `data` 폴더의 최신 파일을 기준으로 삼는다. 이 문서는 해당 파일을 검토하거나 최신성을 확인한 결과가 아니라, 원문의 기준 자료 지정만 정리한 것이다. [근거: 03_업무메일_모음_2025국감.txt 67~68줄](../지침재료/03_업무메일_모음_2025국감.txt#L67-L68)

## 2. 접수

- 요구서를 문항 단위로 대장에 기록하되 하위 ‘가.’·‘나.’는 분리하지 않는다. 접수번호는 ‘연도-일련번호’로 부여한다. [근거: 01_전임자_인수인계서_국회업무_2025.md 9, 13~15줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L9-L15)
- 접수일·국회구분·위원회·의원·요구유형·문항번호·요구내용·요구기간·제출기한·제출형식을 기록한다. 개인정보 제외 등의 주석은 비고에 옮긴다. [근거: 01_전임자_인수인계서_국회업무_2025.md 14~16줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L14-L16)
- 제출기한은 요구서 날짜 그대로 적는다. 날짜 이상과 중복 접수는 [예외](예외.md)에 따라 처리한다. [근거: 01_전임자_인수인계서_국회업무_2025.md 17~18줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L17-L18)

## 3. 배분

- 접수 당일 배분을 원칙으로 한다. 배분기준표의 키워드와 우선순위로 주관 과 후보를 정하고, 사람이 최종 결정한다. 조직도에 없는 과로 보내지 않는다. [근거: 02_2025국감_대응계획_메모.txt 7줄](../지침재료/02_2025국감_대응계획_메모.txt#L7), [01_전임자_인수인계서_국회업무_2025.md 21줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L21), [04_과장님_구두지시_메모.txt 3줄](../지침재료/04_과장님_구두지시_메모.txt#L3)
- 여러 과에 걸치면 주관 과 하나와 협조 과를 정한다. 전 과 공통 문항은 주관 과가 전 과 회신을 취합한다. [근거: 04_과장님_구두지시_메모.txt 5줄](../지침재료/04_과장님_구두지시_메모.txt#L5), [01_전임자_인수인계서_국회업무_2025.md 22줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L22)
- 배분 이의는 배분 메일 수신 후 2시간 안에 알리고 재배분 이력을 남긴다. 종전 ‘당일 중’ 기준의 변경 근거는 [예외](예외.md)에 정리했다. [근거: 03_업무메일_모음_2025국감.txt 17~22줄](../지침재료/03_업무메일_모음_2025국감.txt#L17-L22)

## 4. 회신과 취합

- 배분 시 회신 엑셀 양식을 함께 보낸다. 1행 요구 내용·2행 머리글을 유지하고 열을 추가·삭제하지 않는다. [근거: 01_전임자_인수인계서_국회업무_2025.md 27줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L27), [02_2025국감_대응계획_메모.txt 11줄](../지침재료/02_2025국감_대응계획_메모.txt#L11)
- 각 과는 배분 받은 날부터 3일 안에 회신하되 의원실 기한이 더 빠르면 그 기한을 따른다. 미회신 과는 매일 오전 10시에 메신저로 공지한다. [근거: 02_2025국감_대응계획_메모.txt 8~9줄](../지침재료/02_2025국감_대응계획_메모.txt#L8-L9)
- 금액은 천원 단위로 통일한다. 자료가 없는 연도도 행을 남겨 ‘해당 없음’으로 기재한다. 집행액이 예산보다 크면 비고에 사유를 적는다. [근거: 03_업무메일_모음_2025국감.txt 10~12줄](../지침재료/03_업무메일_모음_2025국감.txt#L10-L12), [01_전임자_인수인계서_국회업무_2025.md 29줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L29)

## 5. 검증

- 빠진 문항·요구기간 연도, 조직도에 없는 부서명, 거꾸로 된 기간, 기한 경과, 합계 불일치, 중복 접수, 띄어쓰기·오타를 점검한다. 이상 사항은 임의 수정하지 않고 ‘확인필요’로 총괄 담당자에게 보내며 확인된 내용만 제출본에 반영한다. [근거: 03_업무메일_모음_2025국감.txt 51~56줄](../지침재료/03_업무메일_모음_2025국감.txt#L51-L56)
- AI가 만든 숫자는 원자료와 대조한 뒤에만 보고서에 사용한다. [근거: 03_업무메일_모음_2025국감.txt 31줄](../지침재료/03_업무메일_모음_2025국감.txt#L31)

## 6. 결재·제출·기록

- 답변 내용과 제출 여부는 결재를 받고, 과장 결재 후 국회 담당이 일괄 제출한다. 개인정보 포함 자료는 마스킹 후 제출한다. [근거: 04_과장님_구두지시_메모.txt 4줄](../지침재료/04_과장님_구두지시_메모.txt#L4), [02_2025국감_대응계획_메모.txt 13~14줄](../지침재료/02_2025국감_대응계획_메모.txt#L13-L14)
- 제출 현황표에는 접수번호별 배분 과·회신 여부·제출일·기한 준수 여부를 기록한다. 처리 내용과 누가·언제·무엇을·왜 했는지를 남긴다. 제출 후 정정은 ‘수정 제출’로 따로 보존한다. [근거: 01_전임자_인수인계서_국회업무_2025.md 38~42줄](../지침재료/01_전임자_인수인계서_국회업무_2025.md#L38-L42), [04_과장님_구두지시_메모.txt 6줄](../지침재료/04_과장님_구두지시_메모.txt#L6)

## 7. 전 단계의 정보보호

- 실제 요구자료는 내부 시스템에서만 다루고 연습에는 가상 자료를 사용한다. 개인정보 자료를 외부 AI에 입력하지 않으며 API 키 등 비밀번호성 정보를 공유 폴더나 코드에 두지 않는다. [근거: 04_과장님_구두지시_메모.txt 7줄](../지침재료/04_과장님_구두지시_메모.txt#L7), [03_업무메일_모음_2025국감.txt 30~32줄](../지침재료/03_업무메일_모음_2025국감.txt#L30-L32)
